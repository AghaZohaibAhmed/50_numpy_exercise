50 NumPy Exercises — Mastering NumPy Fundamentals
This repository contains solutions to the "50 NumPy exercises" challenge — designed to strengthen your understanding of NumPy, the foundational Python library for numerical computing and data science.

✅ 50 handpicked problems covering:

Array creation & manipulation

Data types and broadcasting

Linear algebra operations

Boolean masking & slicing

Aggregation & statistical methods

Advanced indexing and memory tricks

Structured arrays

Vectorization

Memory efficiency

Matrix transformations
